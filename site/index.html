Install

Open it the first time

Brim isn't notarized by Apple yet, so macOS asks you to confirm it once. After that it opens like any other app.

  1. Drag it inOpen Brim.dmg and drag Brim to Applications.
  2. Open itOpen Brim from Applications. macOS says it can't verify it. Choose Done.
  3. Allow itIn System Settings, go to Privacy & Security and choose Open Anyway.
  4. Add an accountClick Brim in the menu bar and sign in to the tools you use.

Questions

Does it cost anything?

No. Brim is free and open source under the MIT license.

Does it send my data anywhere?

Brim has no analytics. It talks to the providers you sign in to, to read your limits. It also checks this site for updates and fetches a public price list from GitHub for its cost estimates.

Does it read my other apps' files?

Only Claude Code's and Codex's usage logs and OpenCode's message history, for the local estimates, which you can turn off. It never reads their credentials. Live Feed is opt-in and backs up your Claude Code settings before changing them.

Will it get around my provider's limits?

No. Brim shows your limits and uses fewer requests to read them. It doesn't change what your plan allows.

Does it update itself?

Yes, from version 0.2.0. Earlier versions need one manual download first.

Does it start when I log in?

Yes. Brim adds itself as a login item when you open it. Turn that off in Settings or System Settings and it stays off.

Who made it?

Purv Taparia, as a fork of OpenUsage by Robin Ebers. Thanks to Robin and its contributors. The Raycast extension is a fork of ccusage for Raycast by nyatinte.

Then it resets

Every limit drains back down. Know when, and plan your next long run around it.
